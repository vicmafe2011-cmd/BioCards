# BioCards · Descifradores de la vida

Aplicación web oficial de la colección educativa BioCards de MIMOA PAPER.

## Funciones

- Colección persistente de 16 BioCards.
- Buscador, filtros y fichas educativas.
- Retos individuales y registro de progreso.
- Duelos al mejor de tres con OBS, DES e IMP.
- Habilidades especiales con justificación.
- Ranking local de victorias.
- Diseño adaptable a ordenador, tableta y móvil.

## Desarrollo

```bash
npm install
npm run dev
```

## Verificación y producción

```bash
npm run check
```

El proyecto está preparado para desplegarse en Vercel con `npm run build` y el
directorio de salida `dist`.
